# 3分本編の進行

[別デッキの3分本編](https://docs.google.com/presentation/d/1nZfflzDYlQgFWedtzofWIgupZD2inLphNzmtGdWG_XA/edit) / [公開の閲覧用PDF](slides-3min-preview.pdf) / [詳細版（10枚）](https://docs.google.com/presentation/d/1KRTMFYQiLugfNoKXPJWCc3JFyjXT8NkxEPqvpC5EvUY/edit)

## 1. 表紙・Team HaaS（15秒）

Team HaaSです。AIが必要な人の力を呼び出し、仕事を最後までつなぐHaaSを提案します。4人の役割は表紙のアイコンで短く紹介します。

## 2. HaaS構想（25秒）

採用に限らず、人の専門性、創造性、共感を必要な単位で届ける構想です。AIだけでは確定できない仕事を、人の出番へつなぎます。

## 3. 仕組み・編集可能な図（35秒）

依頼者から受けた仕事をAIが分解・配分・調整し、人の成果をまとめて返します。図の箱と文字は編集可能です。今回は採用受付を一例に、必要な質問を人へ依頼する流れを検証しました。

## 4. デモ・切替時間込み（60秒）

0〜10秒でデモへ切替。10〜25秒で質問と人への依頼を示し、25〜40秒で同じブラウザの担当者タブで引受・模擬回答。40〜50秒で元タブへの回答反映を示し、50〜60秒でスライドへ戻ります。公開UIはブラウザ内の模擬動作です。実AI APIと模擬人間回答の試験は別記録で、実機通話は未確認です。詰まったら操作を繰り返さず、依頼・引受・結果返却の流れを口頭で説明して次へ進みます。

## 5. 価値・実装境界（25秒）

AIは仕事の調整、人は専門知識や共感・判断を担います。実AI・MCPと模擬回答の単独試験記録はありますが、公開UIとの通し、黒電話の実機、定量的な効果は未検証です。

## 6. 締め（20秒）

AIの『できない』を、人の出番に。HaaSの構想を採用受付から検証しています。表示URLとQRは公開済みのデモ案内ページです。実デモは発表前に開いた公開フロントURLを使います。ここで本編を終了し、補足は詳細版を質疑時だけ使用します。

本編に使わない詳細チーム紹介・技術構成・行動指針は元の10枚資料に残しています。`https://haas.nullevi.app/` は公開済みの案内ページです。5秒でデモへ自動移動し、停止できます。
